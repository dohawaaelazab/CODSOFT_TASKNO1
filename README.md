# Task 1: To-Do List Application (Python & Tkinter)

A desktop-based To-Do List application built with Python and Tkinter that allows users to manage daily tasks efficiently.

## Features
- **Add Tasks**: Quickly insert new tasks into the list.
- **Update Tasks**: Edit existing tasks in real time.
- **Delete Tasks**: Remove tasks from the list when no longer needed.
- **Mark as Done**: Mark tasks complete with a visual checkmark (✔).
- **GUI Interface**: User-friendly layout with custom styling and scrolling support.

## Prerequisites
- Python 3.x
- `tkinter` (included with standard Python installations)

## How to Run
```bash
python to_do_list.py
